# JustWebAnimate

JustWebAnimate is a lightweight 2D animation web app built with plain HTML, CSS, and JavaScript.

It includes:
- a canvas-based animation stage
- addable shapes (rectangle, circle, and text)
- object selection and editing
- timeline scrubber and playback controls
- keyframed motion editing
- JSON export/import

## Run locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — app shell
- `style.css` — layout and styling
- `app.js` — animation logic and editor behavior
